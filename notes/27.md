2 章の最後は、公式 Agent Skills の配布です。

AI エージェントにテーマやプラグインを書かせると、a-blog cms の書き方を知らないため、そのままでは使えないコードになりがちでした。

公開したスキルは 15 あり、サイト制作用、プラグイン開発用、共通の 3 つのプラグインに分けています。Claude Code のほか、Codex や GitHub Copilot、Cursor でも使えます。

**入れたあとは、「お問い合わせフォームを作って」のように、いつもどおり依頼するだけです。**合うスキルをエージェントが選んで読み込みます。対象は a-blog cms の 3.2 以上です。

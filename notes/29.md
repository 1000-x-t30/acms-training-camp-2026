最初に、v3.3 で変わる前提を 3 つお伝えします。

**1 つ目は、最初にご説明した通り　v3.3 で動く PHP が 8.3 から 8.5 になることです。**PHP 8.1 と 8.2 のサポートは終える方針です。今のうちに、サーバーの PHP のバージョンを確認しておいてください。

2 つ目は、Ping 送信の廃止です。ほとんど使われておらず、v3.2.0 から非推奨にしていました。独自のテーマや拡張で Ping 送信を使っている場合は、v3.3 に上げる前に外してください。

3 つ目は、a-blog cms に同梱している jQuery と htmx のアップデートです。jQuery は 3.7 から 4.0 に、htmx は 2 系から 4 系になります。どちらも非互換の変更があるので、テーマの JavaScript や hx- 属性が v3.3 でも動くか確認してください。

ブロックエディターの最後は HTML ブロックです。

これまでは、ブロックエディターの中に自由な HTML を書く手段がありませんでした。

HTML ブロックでは、コードを書きながら、隣でプレビューを確認できます。外部サービスのウィジェットを貼るときなどに使えます。

**注意点として、script や form タグが公開側に出るかどうかは、サーバーの設定ファイルで決まります。**private フォルダの config.system.yaml にある strip_dangerous_tag です。管理画面にはありません。同梱の設定は on で、出力するときに取り除きます。この行がないサイトでは off の扱いになり、書いた HTML がそのまま出ます。使える人を権限で絞る仕組みはないので、担当のサイトの設定を一度確かめてください。
